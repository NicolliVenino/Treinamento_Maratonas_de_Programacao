# Treinamento para Maratonas de Programação

Eu e minha equipe alinhamos de resolver, de forma individual, durante 1 semana, um exercício extretamente difícil de uma área do conhecimento que existe na SBC. Após essa 1 semana, vamos nos reunir para trocar conhecimento e mostrar como chegamos na resolução. 

Para resolver esse exercício é absolutamente proibido o uso de IA para qualquer etapa de desenvolvimento, de modo que urge estudar de fato e buscar resolver execícios menores que abordam a temática e ajudam a levar à solução do exercício da semana. Nesse sentido, a IA será usada única e exclusivamente para recomendar listas de exercícios menores similares e ajudar no aprendizado com conteúdos teóricos, nunca dando dicas ou falando do exercício. Para isso, adicionei no arquivo settings.json do Claude:
```
{
  "permissions": {
    "deny": [
      "Edit(**/resolucao.cpp)"
    ]
  }
}
```
